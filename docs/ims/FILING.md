# Private filing workspace
Nested directories with admin-managed permissions. Admins have full access. Managers can read/write unrestricted folders, or restricted folders with explicit grants at each restricted ancestor. Permission changes and file operations serialize on a DB lock. Separate storage tables prevent older document APIs from bypassing folder ACLs. No direct file paths. Immutable revisions, SHA-256 checks, logged uploads/downloads, local file filter, 5 MiB file and 100 MiB aggregate quota. Existing controlled documents remain in Document Control; this workspace is not a substitute for formal approval, and existing approved files are not moved or reclassified. No external sharing, malware scanning, inline previews, file deletion/move, native Office editing, automatic backups, or external storage adapters implemented. No additional dependencies or subscriptions. Backup MySQL externally and test restore. Existing administrative accounts retain full access. Review permissions before real data use. Rollback via PR revert; retain additive tables. Only admin/manager roles may access the workspace.
